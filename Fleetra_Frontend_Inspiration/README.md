# Fleetra Frontend PHP

Frontend-only recreation based on the supplied Fleetra UI reference screens and assets.

## Run locally

```bash
php -S localhost:8000
```
Then open `http://localhost:8000`.

## Notes
- No database or backend logic is included.
- Shared navigation, header, UI components, CSS and JavaScript are reusable.
- Forms and controls are frontend demonstrations only.
- Responsive layouts are included for tablet and mobile.

## Main pages
Login, dashboards, routes, live operations, fleet, vehicle details, drivers, driver profile, schedules, create schedule, bookings, booking details, seat selection, digital ticket, passengers, maintenance, incidents, analytics, notifications, settings, profile, users/roles, journey planner and live trip.
